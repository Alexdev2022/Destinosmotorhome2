# Destinos — Site

Site estático da Destinos Locação de Motorhomes.

## Estrutura

- `index.html` — estrutura e conteúdo
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile, rolagem e ano do rodapé
- `assets/logo.png` — logotipo fornecido pela Destinos, apenas com margens transparentes aparadas
- `assets/destinos-luna-exterior.jpg` — foto fornecida
- `assets/destinos-lifestyle.jpg` — foto fornecida

## Publicação no GitHub + Netlify

1. Crie um repositório no GitHub, por exemplo `destinos-motorhome`.
2. Envie todos os arquivos desta pasta mantendo a estrutura.
3. No Netlify, escolha **Add new project / Import an existing project** e conecte o repositório do GitHub.
4. Como é um site estático, não é necessário comando de build.
5. Publish directory: `/` (raiz do projeto).
6. Publique.

O site usa apenas HTML, CSS e JavaScript e não precisa de backend.
